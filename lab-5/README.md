# ЛР-5. Події, контрольовані й неконтрольовані компоненти

Лабораторна робота № 5 курсу «Розробка вебзастосунків на React»: форма
бронювання столика в кав'ярні. Інструкція:
https://denysmatsevych.github.io/web-development-2026/react/labs/lab-5/

Форма надсилається без перезавантаження сторінки: `onSubmit` скасовує типову
дію браузера через `preventDefault`, а дані читає `FormData`. Коментар —
контрольоване поле з лічильником символів, Ctrl+Enter (⌘+Enter) надсилає
форму з будь-якого поля, `GuestsStepper` — контрольований компонент із
пропсами `value` і `onChange`, а «Очистити» скидає всю форму й повертає фокус
у поле «Ім'я». Текст підтвердження складає функція з
`src/describeBooking.js`, стилі — у `src/index.css`.

## Команди

`npm install` виконуйте в корені репозиторію `react-labs`, решту — у теці
`lab-5/`:

- `npm run dev`: dev-сервер на http://localhost:5173
- `npm run lint`: ESLint
- `npm run format:check`: перевірка форматування Prettier
- `npm run build`: production-збірка в `dist/`
